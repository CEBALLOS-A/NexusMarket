# Capa — Adapters REST

## Controladores propuestos
PublicCatalog, Buyer, Seller, Administrator, LogisticOperator, Supervisor, Order y AfterSales.

## Responsabilidades
Recibir HTTP, validar DTOs, reconstruir el contexto del usuario autenticado, invocar puertos de entrada y mapear respuestas. No contienen reglas de inventario ni transiciones de pedido.
